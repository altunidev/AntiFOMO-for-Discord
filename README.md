# AntiFOMO-for-Discord
A lightweight Discord CSS modification built to reduce distractions and hide unnecessary UI elements. Best if used with BetterDiscord or Vencord Themes. Can even be used in conjunction with other custom CSS themes!

### Disclosure
This was drafted partially with assistance from ChatGPT (logged out, guest user mode) on the bare minimum featureset. If you have any doubts about the code, the only file I used LLM assistance with is a simple CSS file, which is less than 50 lines. I have personally audited and heavily tested this code. Please do the open source thing and audit it yourself if you have issues with LLM assistance. It's not that hard.
